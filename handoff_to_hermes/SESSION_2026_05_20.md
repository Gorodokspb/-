Работа ведётся через Ollama/Kilo в VS Code.
ChatGPT формулирует точные задачи/промты для Ollama/Kilo.

Правила процесса:
1. Сначала анализ/диагностика.
2. Потом маленькая реализация.
3. Потом тесты.
4. Потом commit.
5. Push только после отдельного подтверждения пользователя.
6. Restart только после push, если менялся код приложения.
7. Live-проверка пользователем в браузере.
8. Этап считается закрытым только после ручной проверки.
