Ключевые решения:
- `contract_settings_json` хранится в `projects.contract_settings_json` (TEXT, JSON blob) — без миграции.

- Двухпроходная замена: paragraph.runs → XML `w:t` elements.
- `_replace_working_group_paragraph()` — paragraph-level replacement (не placeholder).
- `_normalize_replacement_colors()` + `_remove_red_colors()` — финальная нормализация цвета.
- `_replace_in_xml_text_nodes()` — fallback для hidden runs (`rStyle="af2"`).
- `object_address` приоритет: settings → counterparty.work_address → project.address → project.project_name.
- `_normalize_counterparty_type()` — маппинг типов контрагента.
- `Cache-Control: no-store` + `&_t=updated_at` — защита от кэширования браузера.

Routes:
- `POST /projects/{project_id}/contract/generate-docx` — генерация и скачивание.
- `GET /documents/{document_id}/download?kind=file&_t={updated_at}` — скачивание с cache-busting.
